## Publish with GitHub Pages

1. Create a new **public** GitHub repository named `AHelpDiscordBot-Legal`.
2. Push the contents of this directory to its default branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the default branch and `/ (root)`, then save.

The expected policy URL for the GitHub account `Krosus777` is:

```text
https://krosus777.github.io/AHelpDiscordBot-Legal/
```

Use that URL as the application's Privacy Policy URL in the Discord Developer Portal.
